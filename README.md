# minecraft-scripts

| Project | What it is |
| --- | --- |
| [`item-esp-mod/`](item-esp-mod/) | Fabric client mod (1.21.1): ESP boxes, tracers and labels for every dropped item, with an adjustable chunk radius and a full settings UI. Single-player only. |
| [`green-shaders/`](green-shaders/) | OptiFine/Iris shader pack with a green color grade (Emerald, Night Vision and Terminal styles) that keeps PvP gear colors readable. |
| [`green-pvp-pack/`](green-pvp-pack/) | All-in-one resource pack: turns the whole game green on 1.21/1.21.1 by replacing one built-in shader file, plus vine-forged green swords, axes, bows, crossbows, armor and other PvP items with green animations (special lightning trident), a totem drawn from the player skin, special end crystal and obsidian textures, and elytra. `greenify.py` bakes the green into textures for other versions. Every material stays easy to tell apart. Pairs with Green Shaders. |
