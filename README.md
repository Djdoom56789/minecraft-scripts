# minecraft-scripts

| Project | What it is |
| --- | --- |
| [`item-esp-mod/`](item-esp-mod/) | Fabric client mod (1.21.1): ESP boxes, tracers and labels for every dropped item, with an adjustable chunk radius and a full settings UI. Single-player only. |
| [`green-shaders/`](green-shaders/) | OptiFine/Iris shader pack with a green color grade (Emerald, Night Vision and Terminal styles) that keeps PvP gear colors readable. |
| [`green-pvp-pack/`](green-pvp-pack/) | Resource pack: vine-forged green swords, axes, bows, crossbows, armor and other PvP items with green animations (special lightning trident), a totem drawn from the player skin, and every material still easy to tell apart. Pairs with Green Shaders. |
